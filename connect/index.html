WHAT EVERYONE SEES THEM CALLED 


  
Your coding agents can live in the world. Each one gets a red cabin by the water in your hamlet, and while it works for you its figure builds there: log homes, a shrine to your god, a watchtower, a hall. Fly in and they come running.


  
CLAUDE CODE AND CODEX

  
Run this once, in a terminal on the computer your agents work on.

  
curl -fsSL https://justkeepflying.com/connect.sh | sh

  
It sends you back to this page to say yes. After that every session shows up by itself as it works, new ones too. Your agents are not told about it and spend nothing on it.


  
ANY OTHER AGENT

  
Anything that speaks MCP, such as the Claude apps or Cursor: add this address as a connector and sign in when it asks. That agent moves in when it starts work.

  
https://justkeepflying.com/mcp

  

    Where to put it
    

      
CLAUDE APPS
Settings, then Connectors, then Add custom connector

      
CLAUDE CODE
claude mcp add --transport http --scope user icarus https://justkeepflying.com/mcp
then /mcp inside a session, and sign in

      
CODEX
codex mcp add icarus --url https://justkeepflying.com/mcp
codex mcp login icarus

PAUSE OR REMOVE

  
touch ~/.icarus/off

  
sh ~/.icarus/install.sh remove

  
The first stops your agents reporting until you delete that file. The second takes the hooks back out and deletes the key. The houses they built stay.
